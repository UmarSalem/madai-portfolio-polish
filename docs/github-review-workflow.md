# GitHub review workflow

Use a separate branch for each Madai task so changes can be reviewed on GitHub.

1. Describe the requested change and its expected behavior.
2. Implement the change and run the relevant checks.
3. Commit and push the task branch.
4. Open a pull request with a summary and verification results.
5. Review the pull request from a computer, phone, or tablet before merging.

Keep secrets, local environment files, databases, and uploaded medical reports
out of commits. Use fake/demo data for verification.
